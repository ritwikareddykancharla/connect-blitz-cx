01 · Problem

Problem

Maintaining separate chat stacks for customer web widgets, mobile apps, agent workspaces, and supervisor dashboards causes context loss during escalations, slow feature rollouts, and accidental exposure of sensitive notes or payment data.

Omnichannel CX Architecture

Overview

ConnectBlitz unifies the hosted Embedded Communications Widget (ECW), compact mobile sheet, contact-center agent workspace, and supervisor oversight console onto a single configuration-driven protocol. A declarative JSON tenant schema validates WCAG 2.1 AA contrast ratios in 0.01 ms (p50), enforces ISO/IEC 7812 Luhn payment-card and SSN redaction in 0.004 ms (p50), carries verified customer identity and interactive card selections into warm agent handoffs with 0 repeat prompts, and projects every conversation turn across all four surfaces in 2.004 ms (p50) with 0.0% leakage of internal agent or supervisor whispers.

01 · SURFACE DRIFT

Four Separate Frontends Slow Every AI Release

When web chat, mobile SDKs, agent desks, and supervisor monitors use separate rendering models, adding one interactive order picker or updating brand contrast requires four coordinated releases.

02 · REPEATED CONTEXT

Cold Bot Transfers Force Customers to Start Over

Customers verify their account and pick an order in self-service, only to be asked for the exact same order ID and issue summary when an exception routes them to a human specialist.

03 · WHISPER EXPOSURE

Shared Event Streams Risk Leaking Internal Coaching

Supervisor whisper guidance and AI copilot margin caps live alongside public turns in the same contact session, requiring server-side role projection so internal notes never enter customer payloads.

04 · UNSCRUBBED TRANSCRIPTS

Typed Card Numbers Enter Databases and Prompts

Frustrated customers paste 16-digit payment cards, SSNs, and SMS verification codes into chat boxes, exposing PCI and identity secrets unless scrubbed before persistence and model calls.

01 · UNIFIED WIDGET SCHEMA & SURFACE RENDERER connect_blitz/widget_config.py
Administrators maintain a single JSON tenant schema covering brand colors, PII masking style, allowed interactive rich cards, and SLA escalation thresholds. Every valid update compiles fresh contracts for Web ECW, Mobile Compact, Agent Desk, and Supervisor Console at once.
validate_widget_config() computes linearized sRGB relative luminance and enforces WCAG 2.1 AA contrast (>= 4.5:1) on body and button colors in 0.01 ms (p50), validates card schemas (ORDER_PICKER, REFUND_ESTIMATOR, TIME_SLOT_SELECTOR, REPLACEMENT_CONFIRM), and caps mobile sheets to 3 visible options vs. 5 on desktop ECW.
02 · SESSION ENGINE & ZERO-REPEAT WARM HANDOFF connect_blitz/session_engine.py
Customers move from self-service bot interactions to human specialists and supervisor coaching without ever repeating their verified identity, order ID, or card selections. Internal whisper notes are physically excluded from customer responses.
ConnectBlitzSessionEngine runs SQLite with PRAGMA journal_mode=WAL, enforces UNIQUE(contact_id, client_msg_id) to suppress flaky network retries (100 / 100 duplicates suppressed), compiles WarmHandoffPacket payloads across state transitions, and filters surface views in 2.004 ms (p50) with 0 / 200 whisper leaks.
03 · BEDROCK WHISPER COPILOT & SLA RADAR connect_blitz/copilot_whisper.py
Every customer turn is scored for frustration and policy-cap exceptions before CSAT drops. Amazon Bedrock reads only PII-scrubbed context and verified order slots to coach the agent privately and prepare a 1-click specialist response.
evaluate_escalation_radar() computes deterministic frustration and SLA breach scores in under 0.5 ms, triggering supervisor alerts when thresholds cross. CopilotWhisperEngine calls bedrock-runtime Converse on us.amazon.nova-lite-v1:0 (1,492.59 ms p50 across 12 live runs, 617.3 mean tokens) grounded in tenant policy IDs such as POL-NP-DAMAGED-24H.
04 · LUHN PII SCRUBBER & HASH-CHAINED LEDGER connect_blitz/pii_transcript.py · server.py
Payment card numbers, Social Security numbers, and one-time passcodes are redacted before entering SQLite or Amazon Bedrock, while non-Luhn order and tracking numbers remain readable for support workflows.
scrub_transcript_pii() validates 13-to-19 digit candidates with ISO/IEC 7812 Luhn mod-10 in 0.004 ms (p50, 100.0% precision and recall across 40 benchmark cases). ContactAuditLedger chains SHA-256(canonical_json + prev_hash) from GENESIS_CONNECTBLITZ_LEDGER_0000, verifying 429 rows in 3.627 ms.
04 · Trade-Offs

Trade-Offs

ConnectBlitz trades arbitrary custom HTML widgets and persistent WebSocket brokers for strict multi-surface safety, sub-millisecond PII guarantees, and $0.00/hr idle serverless operation.

Architectural Decisions
01 · DECLARATIVE CARDS VS CUSTOM IFRAMES

Bounded Rich-Card Catalog Instead of Arbitrary Tenant Scripts

Tenants choose from five typed card contracts (ORDER_PICKER, REFUND_ESTIMATOR, TIME_SLOT_SELECTOR, IDENTITY_VERIFIER, REPLACEMENT_CONFIRM) rather than injecting custom JavaScript iframes. This prevents XSS inside the Agent Desk and guarantees automatic compact rendering on mobile screens.

02 · SERVER-SIDE PROJECTION VS CLIENT FILTERING

Four Projected Payloads Instead of Hiding Whispers in CSS

Filtering internal coaching messages in browser JavaScript would still expose WHISPER strings inside DevTools network responses. render_contact_bundle() strips non-PUBLIC rows on the server before serialization, achieving 0 / 200 customer payload leaks at a 2.004 ms (p50) projection cost.

03 · DETERMINISTIC LUHN GATE BEFORE LLM

Pre-Storage Regex + Luhn Checksum Instead of Model Redaction

Relying on an LLM to redact card numbers would transmit raw PANs to the model API first and add over a second of latency. Running Luhn mod-10 plus SSA prefix and OTP rules synchronously in Python takes 0.004 ms (p50) before SQLite writes or Bedrock calls occur, while skipping unstructured prose hints.

04 · SERVERLESS LAMBDA + SQLITE WAL

Zero Idle Cloud Cost vs. Ephemeral Container Storage

Hosting /api/* on AWS Lambda /tmp SQLite WAL behind CloudFront keeps idle infrastructure cost at $0.00/hr without NAT Gateways or RDS instances, with the trade-off that demo sessions reset when cold containers recycle. In high-concurrency production fleets, the same session state contract maps cleanly onto DynamoDB + WebSocket API Gateway.
